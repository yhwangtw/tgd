# Verification Before Completion

## Overview

This skill is a compatibility alias, not a parallel source of verification
rules. Load `tgd-core-rules` and apply its **Completion Evidence Gate
(Verification Iron Law)**.

## When to Use

- Before committing or creating a pull request.
- Before any exact, paraphrased, synonymous, or implied statement that work is
  complete, fixed, passing, correct, ready, or otherwise successful.
- Before marking a task complete or advancing to another phase.
- After delegated work, before relying on the delegate's report.

## Required Action

Load `tgd-core-rules` and apply its named **Completion Evidence Gate
(Verification Iron Law)** exactly, including its freshness and current-state
requirements. This alias does not define a second procedure.

## Common Rationalizations

The canonical gate owns the rationalizations and their rebuttals; this alias
does not modify or repeat them.

## Red Flags

The canonical gate owns the red flags. Return to it whenever one applies.

## Verification

Verification is the named gate in `tgd-core-rules`; this compatibility alias
does not maintain a separate checklist.
